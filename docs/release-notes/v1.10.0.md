# Kill Clipper v1.10.0

## Finished edits get their own folder
- Exports from the clip editor are now saved in an **Edited** folder inside your clips folder (`killclips/Edited`), apart from the raw kill clips.
- When an export is saved, it opens straight away in your video player so you can watch the finished edit. With the 9:16 shape on, the vertical version opens once it is made.
- Trimmed videos from the video trimmer also go to the Edited folder and open when saved.
- Clicking the "Saved" message in the editor opens the Edited folder.
- Edited videos also show up in the clip list, so you can find them from the editor.
- To stop exports from opening by themselves, set `"openAfterExport": false` in `config/killclipper.json`.
