First stage of the in-game clip editor: every clip now also saves its fight as a replay.

- **Fight replays.** Next to each video the mod now saves a `.kcreplay` file with the fight itself: every player's movement, hits, crystals and blocks, plus your own movement and gear. The upcoming main-menu editor uses these to show the fight from first person, third person or a free spectator camera. Only clips saved with v1.3.0 or newer will have one, so keep this version installed while you play.
- Replays are small (about 300 KB per minute in testing) and are written in the background at low priority. Turn them off with `saveReplays: false` in the config.
- **Clip file type.** New "File type" button in the settings: MP4 (default), MOV or MKV.

Minecraft 1.21.11, Fabric Loader 0.19.3 or newer, Fabric API, Java 21 or newer. Put `killclipper-1.3.0.jar` in your `mods` folder and remove older `killclipper` jars.
